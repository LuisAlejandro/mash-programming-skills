Mash Programming Skills is a machine-global agent environment for Cursor, OpenCode, and Pi. Its installer distributes Mash Programming Skills, rules, agents, guidance, MCP configuration, and Hindsight hooks into each IDE's global home, refreshing owned global surfaces on every run without writing IDE trees, `AGENTS.md`, `DESIGN.md`, MCP files, pins, or `.mash/*` directories into the current repository.
